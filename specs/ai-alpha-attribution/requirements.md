# AI Alpha 产业链归因需求

## 背景

当前 CN 与 US 使用不同的 AI 分类和不同性质的基准，读者无法横向比较；AI 板块仅展示涨跌，没有像大盘一样解释同交易日驱动。资讯来源也缺少经过身份和权威性核验的 X 原文。

## 范围

本需求覆盖日报的 AI 产业链行情、归因、X 公开资讯采集、发布校验和读者页面。不改变周报核心结构。

## 功能需求

### R1：统一产业链口径

- CN、US 必须使用同一组八个层级：芯片与设备、存储、服务器与算力设备、CPO / 光互连、数据中心电力与液冷、云计算 / NeoCloud、AI 软件与应用、机器人。
- 每个层级必须使用当地市场可交易标的组成的等权代表篮子，不得将 CN 官方行业指数与 US ETF 代理混用。
- 页面必须明确这是代表篮子，不得声称其为官方指数、指数贡献或完整产业分类。
- 每个篮子必须公开成分和当日涨跌，便于读者理解口径。

### R2：AI Alpha 当日归因

- 系统应当在每个市场交易日分别计算八个层级的涨跌并找出领涨、领跌层级。
- 系统应当像大盘归因一样输出 `explained | partial | unattributed` 状态、原因型标题、摘要和 0–4 条驱动。
- 每条驱动必须说明发生了什么、如何传导到具体层级，并引用同交易时段证据。
- 当没有足够证据时，系统必须明确“未发现单一消息主导”，不得猜测或硬凑驱动。

### R3：X 公开资讯

- 系统只应采集已进入白名单的公开 X 账号，并保存原文链接、作者和发布时间。
- 每个账号必须记录身份核验依据与权威等级：官方、专业研究/媒体、行业专家。
- 官方账号可用于确认公司事实；专业研究/媒体可用于解释产业变化；行业专家只可作为线索，不能独立支撑涨跌归因。
- 任何使用 X 的盘面归因都必须同时有一个非 X 来源验证同一事实或同日市场传导。
- 页面应当链接到原始 X 帖子，并以读者可理解的标签展示来源属性。
- X 不可用或没有合格信息时，日报生成不得失败，也不得在读者页面暴露采集诊断。

### R4：三层行情与综合研判

- 日报行情区必须按“大盘指数、行业板块、AI 产业链”三个层级连续展示，三个层级均使用主题墨绿色标题栏。
- 行业板块桌面端必须使用四列网格；每个行业展示四只当地代表标的及其收盘价和当日涨跌，且明确代表标的不等于官方指数成分或加权贡献。
- AI 产业链每只代表标的必须展示收盘价和当日涨跌，格式为“收盘价（涨跌幅）”。
- 每个层级行情下方必须紧邻一组彩虹背景证据列表；不得再展示重复行情的总标题、区间标签或脱离来源的概括句。
- 每条证据必须在同一行项目中绑定文章标题、有效摘要、来源名称与原文链接；高相关证据使用更强的背景或文字强调。
- 每个归因要点必须同时展示可核验事实与传导解释；AI 要点展示事实摘要与产业链影响，不得只保留一句概括。
- 核验来源必须逐条展示原文标题、来源名称和本地化发布时间，多个交叉来源不得合并成无法辨认的标签组。
- 综合研判只能读取已经通过日报质量门的驱动与 AI 产业链动态；X 原帖必须与非 X 权威来源交叉验证后才可显示。
- 当不存在通过验证的原因时，不渲染该层证据列表；不得用“未发现单一消息主导”或涨跌排名复述填充版面，也不得为了显示 X 加入候选信息。

### R5：X 采集可靠性与原文回溯

- 正式采集必须固定使用项目声明的 Python 解释器，并在启动时校验 `twscrape 0.20.0`、可用账号池和 `curl` HTTP 后端；依赖不匹配时必须明确停止 X 子任务，不得静默回退到系统 Python。
- 当唯一可用账号因瞬时网络错误进入不超过 75 秒的冷却时，采集器应等待队列恢复并重试一次；Node 调用方必须为该恢复窗口预留至少 110 秒。
- 内部诊断必须区分采集成功、临时冷却、认证失效、访问拒绝、长期限流、网络异常、依赖缺失和配置缺失，便于定位降级原因。
- 采集器必须解析帖子中的公开外链，并仅在外链域名与白名单账号的官方站点或专业研究站点相符时回溯原文；X 原帖和原始文章必须归并为同一事件的两条证据。
- 系统必须剔除会议宣传、泛品牌内容、无可核验事实的观点和低质量个人推测；只保留包含订单、产品、产能、价格、业绩或明确产业数据的帖子。
- X 失败时日报仍可发布，但不得把历史缓存伪装成本次取得的帖子，也不得向读者展示解释器、账号、错误码或冷却状态等技术诊断。

## EARS 验收标准

- WHEN 用户切换 CN 与 US，THE SYSTEM SHALL 展示完全相同的八个 AI 层级名称与顺序。
- WHEN 某层级行情生成，THE SYSTEM SHALL 展示等权篮子涨跌和构成该篮子的当地标的。
- WHEN AI 驱动被发布，THE SYSTEM SHALL 将其绑定到对应市场、层级、交易日和至少一个可访问证据链接。
- WHEN AI 驱动引用 X，THE SYSTEM SHALL 同时包含至少一个非 X 交叉验证来源。
- IF 只有行业专家帖子或证据发生在归因窗口之外，THEN THE SYSTEM SHALL 拒绝将其发布为 AI 驱动。
- IF 没有可靠催化，THEN THE SYSTEM SHALL 发布未归因状态而不是生成推测性原因。
- WHEN 页面在 1440px 和 390px 宽度渲染，THE SYSTEM SHALL 无横向滚动、裁切或卡片内部横向滑动。
- WHEN 行业板块或 AI 产业链行情生成，THE SYSTEM SHALL 为每个分组展示四只代表标的的收盘价和涨跌幅。
- WHEN 证据列表引用 X 原帖，THE SYSTEM SHALL 在同一列表展示原帖链接、来源属性以及至少一个非 X 交叉验证链接。
- WHEN 一个归因要点包含多个核验来源，THE SYSTEM SHALL 逐条展示每篇原文的标题、来源、发布时间和外链。
- WHEN 某层没有通过验证的 X 证据，THE SYSTEM SHALL 不显示 X 标签或候选原帖。
- IF 某层没有通过验证的原因，THEN THE SYSTEM SHALL 隐藏该层分析区且不输出无归因兜底句。
- WHEN 正式 X 采集启动，THE SYSTEM SHALL 校验指定解释器、依赖版本、账号池和 HTTP 后端，并拒绝使用系统 Python 兜底。
- IF 搜索账号的临时冷却不超过 75 秒，THEN THE SYSTEM SHALL 等待恢复并重试一次，且不得被外层调用提前终止。
- WHEN X 采集降级，THE SYSTEM SHALL 在内部记录可区分的失败类型，同时保持日报主流程可发布。
- WHEN 白名单帖子包含可信官方或专业站点外链，THE SYSTEM SHALL 将帖子与回溯原文作为同一事件的独立证据保留。
- IF X 帖子仅包含宣传、泛化观点或未经非 X 来源验证的个人推测，THEN THE SYSTEM SHALL 拒绝其进入读者页面。
