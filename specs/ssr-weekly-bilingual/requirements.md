# Requirements

1. When a report page is requested, the site shall read D1 and render the report HTML on the server without a client data fetch.
2. When the user switches language, the site shall render navigation and available Agent content in Chinese or English.
3. Each daily report shall include six market metrics, including the Shanghai Composite and CSI 300.
4. Each AI overview shall state positive, negative, or mixed impact and identify affected markets or sectors.
5. The archive shall include a July 24, 2026 report.
6. Every Sunday evening, the local Codex task shall summarize the week, produce conditional next-week scenarios, collect official upcoming events, and persist a traceable weekly report.
7. The repository shall contain one concise maintenance Skill describing architecture, module ownership, and automation entry points.
