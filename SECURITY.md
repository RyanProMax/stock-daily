# Security Policy

## Reporting a vulnerability

Please report vulnerabilities through a private GitHub Security Advisory
(`Security` → `Advisories` → `New draft security advisory`). Do not include
credentials, exploit details, or private data in a public issue.

If a credential is exposed, revoke or rotate it first. Removing it from the
latest file is not sufficient because older commits remain readable until the
Git history is rewritten.

## Supported version

Security fixes are maintained on the default branch.
