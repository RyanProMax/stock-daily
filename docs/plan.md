# 三层行情与综合研判实施计划

1. 行情数据：为 CN、US 各 11 个一级行业维护四只当地代表标的；采集同交易日收盘价与涨跌幅。AI 八层代表篮子沿用现有口径并补充收盘价。
2. 质量门：新采集输入要求行业与 AI 每组 4/4 标的、交易日一致、价格为正；历史 V9 报告继续允许缺失代表标的。
3. 页面结构：市场快照按“大盘指数、行业板块、AI 产业链”展示；标题栏使用主题墨绿，行业与 AI 桌面四列、手机两列。
4. 证据列表：每层网格下方加入彩虹背景的单列证据列表。每条绑定文章标题、摘要、来源和原文链接；删除重复行情标题、区间标签及无归因兜底句，没有可靠驱动时隐藏该层列表。
5. X 证据：只显示进入驱动且同时有非 X 交叉验证的白名单原帖；显示原文链接和来源属性，不展示采集状态或内部评分。
6. 验收：运行 TypeScript、构建、Node 测试；检查 1440px 与 390px 的 CN/US 全页和核心内容，确认无裁切、横向溢出或脱离卡片。
