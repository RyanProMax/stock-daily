# 三层行情与综合研判实施计划

1. 行情数据：为 CN、US 各 11 个一级行业维护四只当地代表标的；采集同交易日收盘价与涨跌幅。AI 八层代表篮子沿用现有口径并补充收盘价。
2. 质量门：新采集输入要求行业与 AI 每组 4/4 标的、交易日一致、价格为正；历史 V9 报告继续允许缺失代表标的。
3. 页面结构：市场快照按“大盘指数、行业板块、AI 产业链”展示；标题栏使用主题墨绿且只保留层级名称，不展示分类数量或代表标的数量等结构说明。行业与 AI 桌面四列、手机两列。
4. 证据列表：每层网格下方加入彩虹背景的紧凑单列证据流。每条采用两行结构：第一行只显示“高亮标题：摘要”，第二行把层级标签和全部来源外链合并为同一组元数据并统一左对齐；手机端只在剩余宽度不足时换行，分类标签与放得下的首条来源保持同行。大盘只承载主驱动，行业只承载次驱动，AI 只承载 AI 动态，禁止同一驱动跨层重复。候选池目标扩为每市场八条以覆盖三层，但最终仍只展示通过归因门槛的独立信息，没有可靠信息时隐藏该层列表。
5. X 证据：先按 CN、US 各自交易窗口过滤候选，再做排序与交叉验证，避免窗口外新帖挤占名额。只显示进入驱动且同时有非 X 交叉验证的白名单原帖；显示原帖链接、来源属性和本地化时间，不展示采集状态或内部评分。采集器异常或搜索队列不可用时必须返回不可用状态，不得伪装成成功的空结果。
6. 页头：V9 日报移除重复的原因型标题、摘要及利好/利空标签，只保留本地化更新时间和日期导航，把阅读重心直接交给三层行情与证据流。
7. 验收：运行 TypeScript、构建、Node 测试；检查 1440px 与 390px 的 CN/US 全页和核心内容，确认无裁切、横向溢出或脱离卡片。
